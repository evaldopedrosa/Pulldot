# Pulldot — simulated site demo

A 12-second, silent product walkthrough made with Remotion. It recreates the Pulldot macOS interface and demonstrates automatic link identification, format and quality choices with estimated size, download progress, and the finished file. The sample Vimeo URL and media are fictional; the animation does not perform a real download.

## Deliverables

- `pulldot-demo-web.mp4`: H.264, 1920×1080, 30 fps, optimized for progressive web playback.
- `pulldot-poster.png`: still frame for a video poster.

## Edit and render

Run `npm install`, then `npm run studio` to preview and edit the composition in `src/Root.tsx`. To render locally, run `npm run render`. The final MP4 uses no audio, so it can autoplay muted on a site.
